# 100

Learning a new skill? Try it 100 times before you're allowed to quit.

Add a skill, tap **I tried** after each attempt, and watch the number count down from 100.
The *Quit* button stays locked until you hit zero.

## Build
Open in Android Studio, or `gradle :app:assembleDebug`. CI builds a debug APK on every push
(Actions → Build APK → artifact `100-debug-apk`).
